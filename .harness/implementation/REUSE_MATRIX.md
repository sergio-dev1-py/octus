# REUSE_MATRIX.md — Matriz de reutilización OpenOrch → Octus

- **Fecha:** 2026-10-30
- **Regla rectora (ADR-001, ADR-012):** Octus se escribe desde cero. En esta matriz, **Reutilizar** significa reutilizar el *concepto, el contrato y el comportamiento verificado* reimplementándolo en Octus con redacción y código propios; nunca copiar código de OpenOrch. Las categorías son las del PROMPT MASTER §3: Reutilizar, Extender, Refactorizar, Reemplazar, Nuevo.

## Notas de lectura

- "Refactorizar" aquí no significa modificar OpenOrch: significa que el concepto existe pero su forma actual no se adopta tal cual en el código nuevo; se reimplementa con la estructura corregida.
- Ninguna fila autoriza copiar implementación. Las referencias `archivo:línea` sirven para *estudiar el comportamiento* durante cada etapa y para escribir pruebas de comportamiento equivalentes en Octus.
- Las filas 38–43 concentran el trabajo realmente nuevo y son el objeto de las Etapas 3–6 del roadmap.
